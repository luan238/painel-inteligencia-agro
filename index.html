🔑 Acesso do botão
Configurar o botão “Atualizar agora” (uma vez por navegador)
O botão pede ao GitHub para rodar o agente na hora. Para isso o GitHub exige uma chave de acesso sua:
  1. Abra GitHub → Fine-grained token → Generate new token.
  2. Repository access: Only select repositories → escolha só o repositório do agente.
  3. Permissions: Actions: Read and write e Contents: Read-only. Defina uma validade (ex.: 90 dias).
  4. Gere, copie e cole abaixo.
A chave fica salva só neste navegador: não vai para o site, para o repositório nem para outras pessoas. Para revogar, apague-a no GitHub.
